安装 Keyphore

适用于 Apple Silicon Mac、macOS 13 或更高版本。需要先安装 Codex 桌面 App 或 CLI。Air65 V3 / Air75 V3（ANSI）已通过 USB 实机测试，其他目录型号预计可采用相同设置，仍待实测验证。

  1. 双击打开 DMG，将 Keyphore 拖入「应用程序」（Applications）文件夹。
  2. 从这个文件夹打开 Keyphore，完成首次引导。根据 macOS 提示确认打开 App；若需要输入监控权限，按照 App 引导操作。
  3. 用 USB 连接键盘并运行信号预览，逐项确认灯光效果。完成安装后可在访达推出 Keyphore 磁盘映像。

后续使用从菜单栏打开设置。退出 Keyphore 会停止信号并熄灯。移除前请先使用 App 内的移除功能，再将 App 移到废纸篓。

Install Keyphore

Requires an Apple Silicon Mac with macOS 13 or later and Codex desktop or CLI installed. Air65 V3 / Air75 V3 (ANSI) have been tested over USB. Other listed models are expected to work with the same settings; compatibility still awaits hands-on testing.

  1. Double-click the DMG and drag Keyphore into the Applications folder.
  2. Open Keyphore from that folder and follow Guided setup. Confirm the macOS first-open prompt; if Input Monitoring is needed, follow the App's instructions.
  3. Connect the keyboard by USB, run Signal preview, and confirm the visible results. You can then eject the Keyphore disk image in Finder.

Open settings from the menu bar. Quit Keyphore to stop signals and turn the signal surface off. Before deleting the App, use its removal flow, then move the App to Trash.
