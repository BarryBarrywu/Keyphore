安装 Keyphore

适用于 Apple Silicon Mac、macOS 13 或更高版本，以及 USB 有线连接的 NuPhy Air65 V3。需要先安装 Codex 桌面 App 或 CLI。

  1. 打开访达，在菜单栏选择「前往」→「个人」。
  2. 打开其中的「应用程序」（Applications）文件夹。如果没有，选择「文件」→「新建文件夹」，命名为 Applications。
  3. 从 Keyphore 磁盘映像中，将 Keyphore 拖入这个文件夹。使用个人文件夹中的 Applications，无需管理员授权。
  4. 从这个文件夹打开 Keyphore，完成首次引导。根据 macOS 提示确认打开 App；若需要输入监控权限，按照 App 引导操作。
  5. 用 USB 连接键盘并运行信号预览，逐项确认灯光效果。完成安装后可在访达推出 Keyphore 磁盘映像。

后续使用从菜单栏打开设置。退出 Keyphore 会停止信号并熄灯。移除前请先使用 App 内的移除功能，再将 App 移到废纸篓。

Install Keyphore

Requires an Apple Silicon Mac with macOS 13 or later, a NuPhy Air65 V3 connected by USB, and an installed Codex desktop app or CLI.

  1. In Finder, choose Go → Home.
  2. Open the Applications folder inside your home folder. If it does not exist, choose File → New Folder and name it Applications.
  3. Drag Keyphore from this disk image into that folder. Installing in your home folder does not require administrator approval.
  4. Open Keyphore from that folder and follow Guided setup. Confirm the macOS first-open prompt; if Input Monitoring is needed, follow the App's instructions.
  5. Connect the keyboard by USB, run Signal preview, and confirm the visible results. You can then eject the Keyphore disk image in Finder.

Open settings from the menu bar. Quit Keyphore to stop signals and turn the signal surface off. Before deleting the App, use its removal flow, then move the App to Trash.
