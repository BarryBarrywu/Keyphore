为你的桌面而生

支持一把通过 USB 有线连接的 NuPhy Air65 V3。首次使用需已安装 Codex 桌面 App 或 CLI；蓝牙、2.4 GHz 和其他键盘型号暂不支持。

留在这台 Mac 上

无需 Keyphore 账户，不自动上传遥测或诊断。仅处理任务状态所需的事件字段，不读取对话、提示词或工具内容。

由你决定

免费使用，源代码不公开。自动检查更新，下载与安装需你批准；任务事件的授权会单独说明。支持简体中文和英文。

从下载到亮灯。

  1. 放入你自己的应用程序文件夹

    打开 DMG。在访达中打开个人文件夹，创建或打开其中的 Applications 文件夹，再将 Keyphore 拖入。查看详细步骤。

  2. 打开 Keyphore，完成引导

    按 App 中的说明连接 Codex、查看任务事件并授权。若 macOS 要求输入监控权限，请按引导完成。

  3. 连接键盘，确认灯光

    用 USB 连接 Air65 V3，运行信号预览并确认目视效果。菜单栏可打开设置；退出 Keyphore 会停止信号并熄灯。
