Before you begin

Install Keyphore

Download app formacOS

Requires an Apple Silicon Mac with macOS 13 or later and Codex desktop or CLI installed.

Air65 V3 / Air75 V3 (ANSI) have been tested over USB. Other listed models are expected to work with the same settings; compatibility still awaits hands-on testing.

  1. Download and double-click the DMG file.
  2. Drag Keyphore into the Applications folder.
  3. Open Keyphore from Applications and follow the setup guide to connect Codex and approve access. If macOS requests Input Monitoring permission, follow the app’s instructions.
  4. Connect your keyboard over USB, run the lighting test in the app, and confirm the result. You can then eject the DMG.

Settings, quitting & removal

Open settings from the menu bar. Closing settings leaves Keyphore running; quitting stops task signals and turns the signal lights off. Before deleting Keyphore, use its in-app removal flow, then move the app to Trash.
